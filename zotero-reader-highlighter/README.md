# Paper Assistant Reader Panel 0.8.1

面向 Zotero 9 自带 PDF 阅读器的英文论文中文覆盖翻译插件。插件只发送筛选后的连续正文段落，不修改 PDF，也不创建 Zotero 批注。

## 安装与首次配置

1. 在 Zotero 中打开“工具 → 插件”。
2. 从文件安装 `reader-text-highlighter-0.8.1.xpi`，覆盖旧版并完全重启 Zotero。
3. 首次启动时输入 DeepSeek API Key。插件通过 `/models` 验证 `deepseek-v4-flash`，成功后保存到 Zotero/Firefox Login Manager。
4. 打开英文 PDF 后，插件自动展开右侧“论文助手”，并从第 1 页开始翻译。

密钥使用 `chrome://paper-assistant`、`DeepSeek API`、`default` 存储，不进入偏好设置、日志、缓存或 XPI。右侧面板可更换、重新验证和删除密钥。

## 0.8.1 版面提取、翻译与显示

- 正文读取只使用 Zotero `pdfDocument.getPageData({ pageIndex })` 的逐字符文本与坐标；不再使用朗读段落，也没有第二条提取回退路径。
- 处理顺序为“字符坐标 → 视觉行 → 栏位 → 阅读顺序 → 逻辑段落”。同一高度的左右栏文字会先按中央沟槽拆成不同视觉行，再按左栏完整结束、右栏随后进入的顺序处理。
- 若 Zotero Reader 已提供结构化文档文本（SDT），插件直接使用其中的 `table`、`caption` 和 `math` 页面区域排除表格、图题与独立公式；没有 SDT 时使用本地几何和文本结构检测。
- 独立公式行不会进入覆盖层或翻译请求；正文段落中的变量字母、希腊字母、上下标和单位仍属于正文字符，不会按字符删除。
- `Fig. 11 shows…`、`Table 2 presents…` 等“编号后直接接谓语”的正文引用会保留；`Fig. 11.`、`Figure 3:` 等强图题格式和真实表题会排除。
- 诊断 JSON 包含栏位、阅读顺序、表格排除、SDT 可用性和字符守恒信息；`unassignedCharacterCount` 与 `duplicateCharacterCount` 用于检查漏字和重复归属。

- 每批最多 5 段或约 2600 个源字符，使用四个并发工作器；请求和显示均按 PDF 前后顺序组织。
- 引用、数字、单位、缩写和变量会先替换为不可翻译占位符，响应后再原样恢复。
- 批内成功段落会直接保留，只重试失败段落，避免单段错误拖累整批。
- 空译文、缺失译文和格式异常响应会在首次请求之外自动重试最多 3 次；后续重试会拆成更小请求，最终失败才进入诊断区。
- 模型返回的代码围栏、前后说明文字和嵌套 JSON 会先由插件安全提取；解析失败会进入内容重试，不直接显示原始 JSON 解析异常。
- 网络错误、429 和 5xx 仍按 1、3、8 秒退避重试；401/403 会停止队列并要求重新配置密钥。
- 覆盖层通过 Zotero 阅读器的坐标转换接口定位，监听缩放、旋转和页面重绘并重新排版。
- 双栏段落按矩形簇独立布局；每段以 Zotero 当前页面主题色遮挡原文，再绘制中文译文。
- 字号由原文行高推定并随页面缩放，可双向放大或缩小以填入原段落高度；放不下时提供“展开”按钮。
- 右侧面板临时显示失败段落的页码、批次、HTTP 状态、请求次数、失败原因和源文预览，便于排查模型响应问题。
- 诊断区可导出不含密钥和译文的版面分段 JSON；文件写入 Zotero 数据目录，用于区分 Zotero 文本层、版面重建和覆盖层问题。
- 编号列表、字母列表、项目符号、标题、图表标题、公式和参考文献作为硬边界；无法确认的边界保持分离并写入诊断信息。
- 跨栏和跨页覆盖层按逻辑片段顺序布局，译文切分优先使用源文字符数；不确定的段落边界保持分离并记录诊断警告。
- 页面重绘前清理旧覆盖层，每个段落使用稳定唯一节点，避免同一译文以不同字号重复堆叠。
- 中文/原文切换统一控制遮罩与译文；原文模式仅保留可点击的“中”按钮。
- 点击中文显示可选择的英文原文，点击小型“中”按钮恢复译文。
- 正文译文保持原覆盖块顶部和底部坐标不变，在固定高度内使用更宽的行间距，并在首行开头加入两格缩进；表题、表格行和单元格均不会进入翻译请求。

## 正文边界与本地缓存

标题、章节标题、图表标题、表格、独立公式、页眉页脚、页码、出版信息，以及 `References/Bibliography` 标题后的内容不会进入翻译请求。

译文缓存在 Zotero 数据目录的 `paper-assistant-translations.sqlite`，不参与 Zotero 同步。缓存键包含文库、附件、页码、段落位置、源文哈希、模型和提示词版本；0.7.0 使用新的提示词版本，旧版失败缓存不会继续影响翻译。

扫描版 PDF 没有文本层时，需要先完成 OCR。

## 兼容性

- Zotero 9.0.x。
- `update_url` 使用保留的 `.invalid` 域名，仅用于清单校验，不对应在线更新服务。
