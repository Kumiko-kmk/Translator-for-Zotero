# Reader Selection Replacer Test 0.4.6

这是一个独立的 Zotero 9.x PDF Reader 测试插件，用于验证：

- 根据用户选区和 PDF 页面数据，按正文段落显示测试替换文字；
- 读取父条目的 `title` 与 `abstractNote`，在 PDF 第一页自动标记标题和摘要。

用户跨栏划选仅在整页栏缝检测失败且选区自身具有充分双栏证据时启用局部恢复，范围限于选区所在垂直区域。未归入正文段落的有效选中字符会作为 `U1`、`U2` 独立组覆盖，避免漏行，并保持后续翻译 segment 接口可用。

## 标题与摘要翻译

- 已可靠定位的英文标题和摘要会转换为统一 `ContentSegment`，打开 PDF 后自动查询本地缓存并使用 DeepSeek 翻译为简体中文。
- API Key 先在线验证，再保存到 Zotero/Firefox 登录管理器；不会写入插件数据库、日志或普通首选项。
- 标题和摘要独立缓存、独立请求和独立失败；成功目标覆盖显示中文，失败目标保留原文诊断边框。
- 成功译文会把同一目标的原始行矩形合并为一个外接矩形，在其中连续换行，并自动选择不溢出的最大中文字号和行距；若最小字号仍无法完整显示，则恢复原文诊断层。
- 工具栏“重译标题/摘要”会绕过缓存重新请求，“DeepSeek Key”用于配置或更换密钥。
- 用户划选的 `P/U` 组已可转换为统一 segment，但本版本暂不自动发送用户划选内容。

## 标题与摘要定位

标题定位保持上一版本的实现不变。摘要定位使用 PDF 视觉行顺序建立文本索引，按前缀、中段和尾部元数据锚点确定同一摘要流，支持普通单栏、左右分栏、全宽跨栏、短尾行、多段摘要和无标题摘要。

摘要覆盖层生成前会重新验证最终区域。只有完整命中首、中、尾锚点，或在可靠版面边界内达到至少 85% 有序词覆盖率时才显示。无法证明完整时显示定位失败诊断，不生成部分覆盖层。左栏 Article Info、作者、机构、日期、DOI、Keywords 和关键词列表不会并入右栏摘要。

自动标记仅使用半透明诊断叠加层，不修改 Zotero 原生选区，不访问私有 `_findController`，不调用网络，也不保存翻译或缓存。

## 使用

1. 运行 `tools/build_reader_selection_replacer_test_xpi.ps1`。
2. 安装 `dist/reader-selection-replacer-test-0.4.6.xpi`。
3. 重启 Zotero 并打开带文字层、父条目标题和摘要的 PDF。
4. 使用 Reader 工具栏按钮可重新执行自动标记。
5. 选择 PDF 文本后，可在选区弹窗中执行测试替换。

## 限制

- 仅支持 Zotero 9.x 普通 PDF 主视图。
- 自动标题和摘要定位只读取 PDF 第一页，并且只读取附件父条目的元数据。
- 没有文字层或 `getPageData()` 失败时不会伪造位置。
- 暂不包含翻译、缓存、OCR、阅读模式和第二视图。
